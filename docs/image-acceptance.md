# 镜像交付验收要求

适用于当前单规格镜像：15 个版本 × amd64/arm64，共 30 个目标镜像。必须对实际导出文件重新导入后测试，构建容器测试与 SHA-256 校验不能替代交付验收。

## 必测：IPv4 / IPv6 双栈

双架构（amd64/arm64）与双栈（IPv4/IPv6）是两回事，两种架构都必须覆盖以下项目。

### 环境前提

- Incus 宿主机内核、网桥、地址分配、路由、DNS 和防火墙均支持 IPv4/IPv6。
- 使用独立测试项目及网桥，不修改已有生产网络；实例不使用特权模式。
- 记录地址来源（IPv4 DHCP、IPv6 SLAAC/DHCPv6 或明确要求的静态配置）、默认路由和 DNS。
- 区分受控网段通信与公网出站。ULA IPv6 可用于局域双栈测试，但不是公网 IPv6 可达证据。
- GitHub-hosted runner 的公网 IPv6 能力必须实测，不能根据 runner 名称假定存在。

### 检查矩阵

| 项目 | 验收要求 |
|---|---|
| 导入启动 | 原始产物在对应原生架构重导入、冷启动成功 |
| IPv4 地址/路由 | 正常获得可用 IPv4 地址及测试网络所需路由 |
| IPv6 地址/路由 | 正常获得非仅 link-local 的 IPv6 地址及测试网络所需路由；只有 `fe80::` 不算通过 |
| 内网双栈 | 分别通过 IPv4/IPv6 与受控对端双向通信；不能只用 ping 判断应用可用 |
| DNS | 能查询预设测试域名的 A 和 AAAA 记录；DNS 解析成功不等于对应协议可达 |
| SSH IPv4 | 从测试端显式使用 `ssh -4`，以验收时设置的临时用户凭据登录并执行 `whoami` |
| SSH IPv6 | 从测试端显式使用 `ssh -6` 执行同样检查，不允许回退 IPv4 |
| HTTPS IPv4 | 对受控双栈 HTTPS 端点使用 `curl -4 --fail --connect-timeout 10 --max-time 30`，校验预期响应 |
| HTTPS IPv6 | 对同一端点使用 `curl -6` 和相同超时，不允许回退 IPv4；禁止 `-k` 或关闭证书校验 |
| 重启持久性 | 重启后重新核验地址/路由、IPv4/IPv6 SSH 与 HTTPS，不要求动态地址字面值保持不变 |
| 公网双栈 | 环境提供公网双栈时，分别检查公网 IPv4/IPv6 出站；公网入站须有对应路由/端口策略和外部测试端，不能从内网成功推定 |

HTTPS 和 SSH 必须实际强制选择地址族。记录 DNS 结果、路由、连接的对端 IP、退出码、预期响应是否符合；不得记录密码、私钥或带凭据的命令参数。测试镜像内 CA 信任库应非空且 HTTPS 证书验证成功，不能只检查 `ca-certificates` 包名。

### 判定与归因

每个镜像、每项检查分别标为 `PASS`、`FAIL`、`BLOCKED`（环境阻塞）或 `NOT_RUN`。同时保留原因和证据：

- IPv6 有地址但无法 SSH/HTTPS，不得标为双栈通过。
- 宿主机自身没有 IPv6 出站时，公网 IPv6 标记 `BLOCKED`，不能猜测是镜像错误，也不能当作通过。
- 受控双栈通过但公网 IPv6 阻塞，只能报告“内网双栈通过，公网 IPv6 未验收”。
- 全量验收包含所有要求项；存在未测/阻塞项时，不签署“公网双栈完整支持”。

## 当前实现与缺口

现有 `scripts/setup-incus.sh` 明确使用 `ipv6.address: none`，构建器的 SSH 测试只选择 IPv4。因此已有 CI 全绿只证明当前构建链路，**未证明双栈支持**。

本文将双栈列为后续验收必测项；本次仅新增验收规范，没有将上述矩阵实现成自动化测试，也没有更改网络预置或宣称任何新双栈实测通过。后续应在同一个工作流内增加原生产物验收，并对无公网 IPv6 的 runner 如实记录阻塞项。

## 其他发布门槛

- 每个目标只有一个完整镜像，文件名无 all/lite；元数据、rootfs 版本和架构一致，校验和及导入正确。
- 预装 bash、git、unzip、screen、wget、curl、sudo、nano、ca-certificates；软件可执行且包数据库可核对。
- root 发布时精确锁定，用户自设凭据后可登录；无临时测试密码及密码备份残留。
- 两个独立克隆必须具有不同 machine-id（适用时）与 SSH 主机密钥；同一实例重启后身份稳定。
- 前次验收发现的克隆身份重复和 RPM `/etc/gshadow-` 残留需独立修复、回归验证，不能因删除 lite 或增加 CA 包视作已解决。
